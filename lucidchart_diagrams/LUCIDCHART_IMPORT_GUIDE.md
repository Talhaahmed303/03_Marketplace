## 1. System Architecture Diagram (`02 - architecture.pdf`)
1. Open [Lucidchart](https://lucid.app).
2. Create a new Blank Document.
3. In the top menu, navigate to **File ➔ Import Data ➔ Mermaid**.
4. Copy and paste the entire code from [`01_ARCHITECTURE_DIAGRAM.mermaid`](01_ARCHITECTURE_DIAGRAM.mermaid).
5. Click **Import**. Lucidchart will generate the 3-tier architecture with Client Layer, Security Boundary, DRF Controllers, and PostgreSQL Database tables.
6. Share Link: Click **Share** (top right) ➔ Set permission to **"Anyone with the link can view/comment"** ➔ Copy Link.
7. Export PDF: Click **File ➔ Export ➔ PDF** ➔ Save as `02 - architecture.pdf` in `03_Marketplace/`.
8. Export PNG: Click **File ➔ Export ➔ PNG** ➔ Save as `02 - architecture.png` in `03_Marketplace/`.

## 2. Database ERD Diagram (`03 - database-design.pdf`)
1. In Lucidchart, create a new document or page.
2. Option A (Mermaid): Go to **File ➔ Import Data ➔ Mermaid** and paste [`02_DATABASE_ERD.mermaid`](02_DATABASE_ERD.mermaid).
3. Option B (SQL DDL): In the left shape panel, click **+ Shapes** ➔ Search **Entity Relationship** ➔ Click **Import** ➔ Select **PostgreSQL** ➔ Paste [`02_DATABASE_ERD.sql`](02_DATABASE_ERD.sql).
4. Share Link: Set to **"Anyone with the link can view/comment"** ➔ Copy Link.
5. Export PDF: Save as `03 - database-design.pdf` in `03_Marketplace/`.
6. Export PNG: Save as `03 - database-design.png` in `03_Marketplace/`.
